# 渠道配置

「配置 → 服务商」里每个渠道只有三件事要填：**协议、地址、密钥**。协议只有两种，不再有自定义脚本或站点预设。

| 协议 | 适用 | 生图 | 对话 | 视频 | 音频 |
| --- | --- | --- | --- | --- | --- |
| OpenAI | 官方 API 与绝大多数中转站 | `/images/generations`、`/images/edits` | `/responses`（Agent 决策走 `/chat/completions`） | `/videos` | `/audio/speech` |
| Gemini | Google AI Studio / Vertex 风格地址 | `:generateContent` | `:streamGenerateContent` | `:predictLongRunning` | 不支持 |

一个渠道一个地址一把密钥。文本和绘图在同一个站点上是两套额度时，就建两个渠道，不要共用一个 Key。

## 一键验证

「配置连接」右侧的**一键验证**用一个请求回答两个问题：

- **地址检测**：`地址可达（HTTP 401）` 说明域名和网络没问题，401 只是没带对密钥；`地址不可达` 才是网络或域名问题。
- **协议握手**：`握手成功，发现 650 个模型` 说明地址、密钥、协议三者都对上了；失败会带回上游原文。

改动地址、密钥或协议后结果自动清空，避免拿旧结果误判。

## 参数差异

Gemini 没有 `quality` 参数，只有尺寸档（`imageSize` 512 / 1K / 2K / 4K）和宽高比；所以切换模型时质量选项会自动收窄。OpenAI 的 `quality` 只对支持的模型开放，选到不支持的值会直接报错，不会静默降级。

## 排错

- **拉模型 401**：这个渠道的 Key 填错，或把文本的 Key 填到了绘图渠道。
- **拉模型超时**：检查 Base URL 是否是站点当前给的地址；带不带 `/v1` 都可以，系统会补齐。
- **生图一直转圈**：看网络面板里提交是否返回了图片、`pollUrl` 或任务 ID；有任务 ID 说明上游在排队，不要重复提交，避免重复扣费。
- **协议报"与模型能力不匹配"**：模型的能力类型选错了（例如把生图模型标成了对话），在模型行改正即可。
